## Instalar no Windows

1. Confira **Configurações → Sistema → Sobre → Tipo de sistema**. Escolha x64 para Intel/AMD ou ARM64 para um PC com processador ARM.
2. Execute o instalador e siga o assistente. Os componentes necessários vêm no pacote; a instalação é para sua conta e cria um atalho no menu Iniciar.
3. Abra o Nook pelo menu Iniciar. O notch aparece no topo da tela e o ícone fica na bandeja, perto do relógio.

**Atualizar:** encerre o Nook pela bandeja e execute o novo instalador. **Desinstalar:** use Configurações → Aplicativos → Aplicativos instalados.

A beta ainda não tem assinatura de distribuição. Alguns PCs gerenciados e configurações do Windows podem bloquear apps sem assinatura. [Informações da Microsoft](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions).

## Instalar no macOS

1. Abra o arquivo `.dmg` e arraste o Nook para Aplicativos.
2. Ejete a imagem de disco e abra o Nook em Aplicativos.
3. A beta ainda não é notarizada pela Apple. Se houver um aviso de verificação, consulte o [guia da Apple para abrir apps de desenvolvedores não identificados](https://support.apple.com/pt-br/102445).

Para atualizar, encerre o Nook antes de substituir a cópia em Aplicativos. Esta release mantém o mesmo pacote macOS 0.11.0-beta.
